# Maintenance Documentation Index

This folder is the operational documentation hub for `aldrinpadua.github.io`.

## Purpose

- Keep a timestamped record of major repository updates
- Provide deployment instructions
- Provide maintainer/end-user guidance
- Standardize how future updates are logged

## Files

- `CHANGELOG.md`: chronological summary of meaningful updates
- `SESSION_LOG_2026-03-07.md`: detailed timestamped log of work completed on March 7, 2026
- `DEPLOYMENT_RUNBOOK.md`: deployment and rollback guidance for GitHub Pages
- `MAINTAINER_GUIDE.md`: maintenance, quality checks, and update workflow
- `LOGGING_POLICY.md`: required process for logging all future updates
- `UPDATE_TEMPLATE.md`: copy/paste template for future entries

## Quick Rule for Future Changes

For every non-trivial update:

1. Append summary in `CHANGELOG.md`
2. Add a timestamped entry to the current session log file (or create a new dated one)
3. Follow the checklist in `MAINTAINER_GUIDE.md`
